Official documentation website and knowledge repository for Redmi Note 8 Pro custom development, ROMs, kernel configuration, and troubleshooting.

---

## 📖 Content Structure

* **Guides**:
  * Bootloader unlocking walkthroughs.
  * Dynamic partition flashing and clean flashing techniques.
  * Play Integrity fixes and Magisk/KernelSU/APatch setups.
  * KProfiles, battery cycle resets, and fast charging optimizations.
  * Camera XML configs (LMC 8.4) and audio optimizations.
* **Troubleshooting**:
  * TWRP decryption and password issues.
  * Bootloop recovery and fastboot rescue procedures.
  * Camera crashes, widevine L3 recovery, and fingerprint fixes.
  * OTG, Bluetooth latency, and battery drain diagnostics.
* **Files & Mirrors**:
  * TWRP, PBRP, and OrangeFox dynamic recovery downloads.
  * Kernel download mirrors and ROM repository lists.

## 🌐 Local Preview

Run any local static web server from the repository root:

```bash
# Python 3
python3 -m http.server 8080

# Or npx serve
npx serve .
```

Open `http://localhost:8080` in your browser.
