# Non-Dynamic Recovery (A11 Base)

If you are running an older Android 11 custom ROM (like older builds of PixelExperience) or the official MIUI 12.5, you MUST use a non-dynamic recovery. 

> [!WARNING]
> Flashing a dynamic recovery on a non-dynamic ROM will result in an inability to mount the system partition.

## Installation
Flash via PC: `fastboot flash recovery recovery_a11.img`
