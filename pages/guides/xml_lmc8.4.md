# LMC 8.4 XML Configs

The stock LMC 8.4 app is a blank canvas. To make it work with Begonia's 64MP GW1 sensor, wide-angle lens, and macro lens, you need a configuration XML.

## Recommended Configs
Check the Telegram dumps for these popular XMLs:
- **IronMan.xml:** Best for high-contrast, moody, cinematic shots.
- **Natural_Begonia.xml:** Best for true-to-life colors and human skin tones.
- **NightOwl.xml:** Maximize exposure time for astrophotography.

## How to Apply
1. Move the `.xml` file to `Internal Storage/LMC8.4/Configs/`.
2. Open the GCam app.
3. Double-tap the black area around the shutter button.
4. Select the config from the dropdown and hit **Import**.
