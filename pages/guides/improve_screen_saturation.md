# Improve Screen Saturation

The Redmi Note 8 Pro has an IPS LCD display. While accurate, it lacks the punchy, vivid colors of an AMOLED screen. 

## Kernel Color Control (KCAL)
To boost saturation, you need a custom kernel that supports KCAL (like Foxy Kernel) and a kernel manager app.

1. Open Franco Kernel Manager (or SmartPack).
2. Navigate to the **Screen** or **KCAL** section.
3. Adjust the **Saturation** slider from the default `255` up to `280` or `300`.
4. Adjust the **Contrast** slightly higher (e.g., `260`).
5. Toggle "Apply on boot".

Your display will now look much closer to a Samsung AMOLED panel!
