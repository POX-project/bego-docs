# Audio Optimize & Bass Boost

If you feel the Begonia's single downward-firing speaker or headphone output lacks depth, this Magisk module combo will dramatically improve your audio experience.

## Requirements
- Root access via Magisk or KernelSU
- [Audio Modification Library (AML)] - Install from Magisk repo.

## Installation Steps
1. Open the Magisk app and go to the **Modules** tab.
2. Install **AML** first and reboot.
3. Download the `Begonia_Audio_Optimize_v2.zip` from the [Begonia Dump Telegram](https://t.me/begoniadump789).
4. Flash the zip in Magisk.
5. Reboot your device.

> [!TIP]
> Combine this with Viper4Android for extreme granular control over bass response, clarity, and convolution profiles.
