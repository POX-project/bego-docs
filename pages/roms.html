Flashing Custom ROMs

With TWRP installed, you are ready to flash a new Android experience.

Pre-installation Check
Make sure you are on the correct firmware version (Android 10/11 MIUI base) required by the Custom ROM before proceeding. Flashing on the wrong firmware can result in a bootloop.

Wiping Partitions

Before installing a new ROM, you must format your current system to ensure a clean slate.

  1. Boot into TWRP Recovery (Hold Volume Up + Power).
  2. Go to Wipe > Advanced Wipe.
  3. Select the following partitions:
    • Dalvik / ART Cache
    • System
    • Data
    • Cache
  4. Swipe to Wipe.

Installing the ROM

Now, flash the ROM zip file.

  1. Go back to the TWRP home menu.
  2. Select Install.
  3. Navigate to the folder where you placed the Custom ROM .zip file.
  4. Select the file and Swipe to confirm Flash.
  5. (Optional) If the ROM does not include GApps (Google Apps), flash the GApps zip immediately after the ROM.

Format Data

This is a crucial step for Begonia to prevent encryption issues.

1. Go to TWRP Home > Wipe > Format Data
2. Type "yes" and confirm.

Finally, go to Reboot > System. The first boot may take 5-10 minutes. Be patient!
